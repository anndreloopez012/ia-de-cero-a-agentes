# Taller Práctico: IA de cero a Agentes

### Sitio del taller: **https://anndreloopez012.github.io/ia-de-cero-a-agentes/**

Herramienta de trabajo de **AI Academy by Campuslands** para dar el taller en el aula. Cada tema trae un video que lo explica como un maestro y una hoja de trabajo para practicarlo.

> La IA útil se construye como una casa: primero se preparan los cimientos, después se dibujan planos claros, luego se organizan herramientas reutilizables y, por último, se coordina un equipo capaz de trabajar con autonomía limitada y supervisión humana.

## El taller en números

| | |
|---|---|
| **Clases** | 4 clases presenciales de 4 horas (16 horas en total) |
| **Temas** | 21, cada uno con un video "modo maestro" de 40–44 s |
| **Ejercicios** | 21 ejercicios individuales guiados |
| **Metodología** | 50 % teoría y 50 % práctica: por clase, 110 min de teoría, 110 min de práctica y 20 min de pausas |
| **Público** | Cualquier persona adulta con ganas de aprender IA aplicada. No se necesita saber programar |
| **Plataformas** | ChatGPT, Claude o Gemini: cada persona trabaja con una sola, la que elija. Clases 1 y 2 con cuenta gratuita; desde la clase 3 se necesita una suscripción de pago |
| **Seguridad** | Todos los ejercicios usan datos ficticios, públicos, autorizados o anonimizados |
| **Contexto** | Ejercicios con situaciones de Guatemala: la tienda de barrio, el comedor del mercado, la cooperativa, el comité de la feria, trámites en la municipalidad y montos en quetzales |

Cada tema sigue el mismo ciclo: **Entender → Ver → Hacer → Probar → Explicar**.

En la primera clase se proyecta el **recorrido animado del taller** (1 min 44 s): el edificio de cuatro pisos se construye clase por clase y muestra los 21 temas. Está en la portada del sitio.

## Contenido de las cuatro clases

### Clase 1 · Cimientos: configuración y fundamentos
**Pregunta guía:** ¿Cómo preparo ChatGPT, Claude o Gemini para trabajar con claridad, seguridad y criterio?
**Te llevas:** pasaporte de configuración de tu plataforma, glosario personal y biblioteca de 20 comandos.

| Punto | Tema | Analogía del video | Ejercicio |
|---|---|---|---|
| 1.1 | Qué es y qué no es una IA generativa | Un autocompletado gigante | Desarmar una respuesta · 25 min |
| 1.2 | Privacidad, autorización y semáforo de datos | Una casa con tres puertas | Convertir un caso amarillo en uno verde · 20 min |
| 1.3 | Configurar ChatGPT, Claude o Gemini | El tablero eléctrico de la casa | Pasaporte de configuración · 20 min |
| 1.4 | Vocabulario que se usará durante todo el taller | Una obra con su equipo | Mapa de conceptos con decisiones · 20 min |
| 1.5 | Elegir el recurso correcto y usar 20 comandos esenciales | Para cada trabajo, su herramienta | Circuito de comandos · 25 min |

### Clase 2 · Planos: prompts ROCAV
**Pregunta guía:** ¿Cómo convierto una intención en instrucciones que otra persona pueda comprender, ejecutar y evaluar?
**Te llevas:** portafolio de cinco prompts ROCAV (Rol, Objetivo, Contexto, Acuerdos y Verificación) con versión inicial, versión mejorada, evaluación y aprendizaje.

| Punto | Tema | Analogía del video | Ejercicio |
|---|---|---|---|
| 2.1 | Anatomía de un prompt | Encargar una mesa al carpintero | Radiografía de una petición vaga · 25 min |
| 2.2 | Construir con ROCAV | Un plano para que todos construyan lo mismo | Del deseo al plano ROCAV · 25 min |
| 2.3 | Patrones de control que se pueden reutilizar | Letreros que sirven en cualquier obra | Fuente cerrada y vacíos visibles · 20 min |
| 2.4 | Loop de mejora: cambiar una variable y aprender | Corregir una receta, una cosa a la vez | Comparación A/B controlada · 25 min |
| 2.5 | Evaluar y transferir un prompt | La revisión técnica del carro | Prueba de transferencia · 15 min |

### Clase 3 · Herramientas: skills reutilizables
**Pregunta guía:** ¿Cómo convierto una tarea que ya sé resolver en un procedimiento que pueda reutilizar y probar?
**Te llevas:** Skill 1.0 con ficha portable y pruebas de caso feliz, caso borde, fallo y no activación.
**Requisito:** suscripción de pago activa en ChatGPT, Claude o Gemini (se usa también en la clase 4).

| Punto | Tema | Analogía del video | Ejercicio |
|---|---|---|---|
| 3.1 | Elegir entre prompt, plantilla, proyecto, herramienta, workflow, skill y agente | No traes una grúa para colgar un cuadro | Diagnóstico del recurso mínimo · 20 min |
| 3.2 | Las ocho partes de una skill | Una herramienta con su manual | Construir la ficha 0.1 · 25 min |
| 3.3 | Trigger, hook, fallback y límites de activación | El control de un aeropuerto | Matriz de activación · 25 min |
| 3.4 | De ficha portable a implementación | Un cargador, tres adaptadores | Implementar sin perder portabilidad · 20 min |
| 3.5 | Probar, corregir y versionar | La escalera que se certifica | Llevar la skill a versión 1.0 · 20 min |

### Clase 4 · Equipo autónomo: agentes y subagentes responsables
**Pregunta guía:** ¿Cómo construyo un sistema que continúe por varios pasos, delegue trabajo y se detenga ante riesgos?
**Te llevas:** agente coordinador, dos subagentes, ficha de arquitectura, contratos de delegación, tres pruebas y demostración final de tres minutos.

| Punto | Tema | Analogía del video | Ejercicio |
|---|---|---|---|
| 4.1 | Distinguir workflow y agente | ¿Tren o taxi con GPS? | ¿Ruta fija o decisión controlada? · 15 min |
| 4.2 | Diseñar un loop con límite y salida | Un horno con temporizador | Loop de máximo cuatro ciclos · 20 min |
| 4.3 | Diseñar el agente coordinador y dos subagentes | El maestro de obra y sus cuadrillas | Prototipo 0.1 del equipo · 25 min |
| 4.4 | Contratos de delegación y handoff | Una orden de trabajo, no un «encárgate» | Dos contratos que se pueden auditar · 20 min |
| 4.5 | Herramientas, permisos, hooks, guardrails y humano en el ciclo | Las llaves del edificio | Matriz de riesgo y controles · 20 min |
| 4.6 | Trazas, pruebas y demostración final | La caja negra del avión | Sistema 1.0 y demostración · 10 min |

## Lo que cada persona construye

1. Pasaporte de configuración de la plataforma elegida: ChatGPT, Claude o Gemini.
2. Glosario personal de conceptos esenciales.
3. Biblioteca de 20 comandos con ejemplos.
4. Cinco prompts ROCAV con antes/después y rúbrica.
5. Skill 1.0 con activación, entradas, pasos, salida, límites y control.
6. Pruebas de caso feliz, borde, fallo y no activación.
7. Agente coordinador funcional con objetivo, estado, loop, herramientas, permisos, hooks, guardrails y traza.
8. Dos subagentes especializados con roles diferentes y contratos de delegación.
9. Tres pruebas del sistema: caso feliz, fallo de subagente y acción que exige aprobación.
10. Demostración final y explicación de tres minutos.
11. Plantillas de trabajo y plan de práctica de siete días.

### Rúbrica del proyecto final (100 puntos)

Problema 10 · Prompt y contexto 10 · Skill 10 · Loop 15 · Coordinación de subagentes 15 · Herramientas 10 · Seguridad y aprobación 15 · Trazas y evidencia 10 · Explicación 5.

### Plan de práctica de siete días

1. Revisar el pasaporte y desactivar una opción innecesaria.
2. Aplicar tres comandos a una fuente ficticia.
3. Mejorar un prompt cambiando una sola variable.
4. Probar ese prompt con un caso distinto.
5. Actualizar la skill con un caso de fallo.
6. Simular un loop con máximo cuatro ciclos.
7. Explicar el sistema a otra persona en tres minutos.

## Cómo se usa el sitio

- **Vista filtrable** en la barra superior: *Todo*, *Solo teoría* o *Solo ejercicios* (teclas `1`, `2`, `3`).
- **Videos "modo maestro":** pregunta → analogía → diagrama paso a paso con subtítulo → idea clave. El reproductor tiene capítulos y al lado muestra el texto de lo que explica.
- **Hojas de trabajo:** material del caso, pasos que se marcan, temporizador con la duración del ejercicio, ejemplo copiable, qué se entrega y cómo saber si se logró. Se pueden imprimir.
- **Modo presentación** (`P`) para proyectar: video a pantalla completa y ejercicio con pasos grandes y temporizador (`T`).
- **Ruta de 240 minutos** de cada clase en una barra de teoría, práctica y pausas.
- **Búsqueda** (`/`), **glosario** de 37 términos (`G`), **avance** guardado en el navegador, tema claro y oscuro y diseño para celular. `?` muestra todos los atajos.

## Para quien mantiene el repositorio

```
planning/CURRICULUM_SITE.md          fuente académica (única fuente del contenido)
scripts/build-content.mjs            currículo → site/content/course-content.js
scripts/build-explainers.mjs         escenas → site/content/explainers.js (capítulos y texto de los videos)
scripts/validate-site.mjs            validación del sitio
site/                                sitio estático que publica GitHub Pages
motion/point-explainers/             los 21 videos (una escena de HyperFrames por punto)
motion/recorrido-taller/             recorrido animado de la primera clase (npm run render dentro de la carpeta)
```

```bash
npm run build:content   # después de editar el currículo
npm run serve           # http://localhost:8817
npm run check           # validación
```

Videos: la guía para escribir una escena está en `motion/point-explainers/AUTHORING.md`. Para renderizar:

```bash
cd motion/point-explainers
node render-all.mjs c2p3   # una escena
node render-all.mjs        # las 21, con pósteres y capítulos
```

GitHub Pages publica `site/` con cada push a `main` (`.github/workflows/pages.yml`).
